# 部署与模型接入

推荐部署环境为 NVIDIA T4 16GB、8 核 CPU、32GB 内存和不少于 100GB SSD，运行环境为 Python 3.12、PyTorch 2.10.0、torchvision 0.25.0、CUDA 12.8 与 cuDNN 9。部署前应根据实际并发量验证显存占用、吞吐和端到端响应时间。

系统由 Vue 3 前端、Express 业务服务、MySQL 数据库和 FastAPI 模型服务组成。浏览器只访问 Express；Express 负责校验、持久化和任务编排，再通过内部 HTTP 调用 FastAPI。正式模型接入时应保持 FastAPI 的请求与响应契约不变，即可替换当前模拟推理而无需重写前端。

智能助手的大模型访问凭据只保存在服务端环境变量中，不能写入前端或展示在页面中。外部大模型接口不可用时，助手会自动回退到本地知识检索，不影响检查、批量分析和结果文件功能。
