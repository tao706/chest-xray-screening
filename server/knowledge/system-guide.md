# 系统使用手册

新建检查时填写 Subject_id 和 Study_id，并上传同一次检查的一张或多张 JPG、JPEG、PNG 胸片。单次最多 20 张，单张不超过 10MB。提交后 Vue 将图片发送给 Express，Express 调用 FastAPI，并将十四类概率保存到 MySQL。

批量分析使用系统已配置的数据集。先在批量推理页面选择并扫描数据集，确认检查与图片数量，再创建后台任务。页面会实时显示扫描、处理、完成和失败进度。

检查记录页面可以按编号和状态筛选历史检查；检查详情展示图片元数据和十四类概率。首页“模型与服务”区域显示 Express、MySQL、FastAPI 和模型的简要运行状态，内部健康检查接口用于启动检测和故障定位。
