# 常见故障处理

推理失败时先查看首页“模型与服务”摘要，检查 Express、MySQL、FastAPI 和模型加载状态。FastAPI 离线时应先启动模型服务；MySQL 异常时检查服务是否运行以及 server/.env 中的连接配置。

图片上传失败时检查文件是否为 JPG、JPEG 或 PNG、是否为空、单张是否超过 10MB、数量是否超过 20 张。Study_id 已存在时应更换编号，或在确认旧记录不再需要后从检查记录页面删除。

SSE 连接中断不代表后台批量任务停止。可以刷新任务状态或重新进入批量推理页面；后台任务仍会继续处理。CSV 校验失败时应根据报告检查失败 Study、缺失 Study、重复组合和字段顺序。
