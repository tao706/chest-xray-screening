# 当前十四类标签说明

当前分析采用队友提供的xray-project权重及其输出顺序。类别如下：

1. 肺不张（Atelectasis）
2. 心影扩大（Cardiomegaly）
3. 肺部实变（Consolidation）
4. 肺水肿（Edema）
5. 胸腔积液（Effusion）
6. 肺气肿（Emphysema）
7. 肺纤维化（Fibrosis）
8. 膈疝（Hernia）
9. 肺浸润（Infiltration）
10. 肺部肿块（Mass）
11. 肺结节（Nodule）
12. 胸膜增厚（Pleural_Thickening）
13. 肺炎（Pneumonia）
14. 气胸（Pneumothorax）

当前标签不包含“无异常发现”（No Finding）、“纵隔心影增大”或“肺部阴影”。低于显示阈值不代表正常，也不能据此排除疾病。旧检查可能保留旧版标签，应以该条记录保存的名称和版本为准，不按当前编号重新解释。

这是多标签分类，同一次检查可以有多项评分较高。系统保存完整14项原始分数，显示阈值只影响突出显示，导出阈值影响结果筛选，不重新计算原始分数。

Grad-CAM显示网络对所选类别的关注区域，不输出病灶检测框，不代表已证实的病灶位置。智能助手基于结构化结果和检索资料回答，不直接识别上传胸片。
