# 开源发布准备

## 第一步：公开内容检查

主工程为无注释版本。当前目录是本地工作目录，不能直接压缩作为公开发行包。

`npm run check:release` 扫描候选源码和文档，检查本地配置凭据是否出现在公开候选文件中、常见密钥形态、私人用户路径以及关键排除规则。输出仅含位置和问题类型。该命令不代替人工检查，也不审计Git历史。

公开候选范围是根目录说明与包配置、frontend/server/inference源码和依赖清单、scripts、database结构、docs。必须排除.env、node_modules、dist、Python环境、权重、数据集、日志、上传、导出和进程记录。模型权重与样例图片只有在后续授权核对通过后才能另行加入。

本地配置、图片、权重和数据库均保留。首次创建管理员必须设置AUTH_DEMO_PASSWORD，源码不再提供固定密码。已有数据库账号的密码不因源码修改自动变化。

当前未发现项目根目录.git，尚不能声称已审查历史提交。初始化仓库后，还需核查实际暂存文件，并在公开前检查所有提交历史。
