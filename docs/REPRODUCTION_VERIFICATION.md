## 检查发现及修复

校验缓存最初在检查图像内容前判断准入服务状态，导致明显无效图片在服务未就绪时返回503，覆盖了原本的422图片错误。已调整为：未命中缓存时先进行格式和图像规则校验，再进行语义校验；命中缓存时仍检查准入服务状态。现有输入拦截测试重新通过。

## 使用者准备

参照 README 的快速开始，准备 Node.js、Python 3.12 与运行中的 MySQL，然后执行 `npm run quickstart`。配置自己的数据库连接与初始管理员，并允许下载依赖和两类模型。在线语言服务密钥为可选配置。更新已有安装时先停止服务，再执行 `npm run setup` 重新构建，随后启动；只下载最新源码不会更新已运行的旧构建。
