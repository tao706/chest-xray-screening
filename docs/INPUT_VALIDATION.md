# 影像输入校验

疾病分类权重不是胸片识别器，不能用疾病分数判断输入是否为胸片。输入必须先通过格式规则和本地图像语义校验，再进入疾病分析。

规则检查实际编码、尺寸、颜色、对比度、噪声和多角度表格线。语义校验使用本地 CLIP 图文特征，比较胸部X线描述和人物、风景、文档、其他成像等负向描述。图像不发送到外部服务。

使用 openai/clip-vit-base-patch32，固定版本 3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268。当前要求最大正向余弦相似度至少0.25，且高于最大负向相似度至少0.04；这些是工程准入阈值，不是医学概率，也未完成外部校准。

选图时前端请求 /api/studies/validate-image，校验未完成或失败时不能提交。单次分析、批量分析和Grad-CAM在Python入口重复执行校验。拒绝时返回422及INVALID_CHEST_IMAGE；校验模型不可用时返回503或阻止服务启动，不能跳过校验或回退到疾病分析。服务仅缓存最多256个图像摘要及判定，不缓存原图。

单次上传成功分析后才保存检查与图片。批量不合格输入记为失败，不创建或覆盖该检查结果。已存在的历史记录不会自动删除。

本地回归：两张随附CC0胸片通过；人物照片、日常场景照片及它们的灰度版本被语义校验拒绝。负向测试照片不随项目发布。ci-image-input.py覆盖8项规则、端点、不可用和缓存行为测试；CI不下载真实校验权重。

CLIP是通用研究模型，不是经过临床验证的胸片模态分类器。当前样本有限，仍可能漏检或误拒；正式部署前需要独立、具有代表性的胸片与非胸片数据集，评估漏放率和误拒率。通过校验不表示影像正常。
