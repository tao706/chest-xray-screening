# 功能演示指南

本指南介绍主要功能的操作顺序。界面截图和操作动图见[README](../README.md#功能展示)。

## 准备

按INSTALL_WINDOWS.md启动服务。登录本地配置账号，可使用examples/chest-xrays中的公开样例，来源及许可见该目录README。演示编号使用不关联真实患者的标识，例如DEMO_SUBJECT_01和DEMO_STUDY_01。

| 顺序 | 页面 | 操作与观察点 |
| --- | --- | --- |
| 1 | /dashboard | 查看统计、最近检查和类别计数；不使用旧版首页布局作为展示 |
| 2 | /studies/new | 填编号、上传图片，演示预览、缩放与校验反馈，再提交分析 |
| 3 | 结果页 | 查看14项评分，调整阈值、排序；强调原始分数没有因阈值改变 |
| 4 | 结果页图片区 | 选择类别生成Grad-CAM，演示透明度与原图对照；说明关注区域不是病灶框 |
| 5 | /studies | 按编号查询，刷新后读取保存的检查，查看原图与详情 |
| 6 | /batch | 选择本地数据集、扫描、创建任务，观察SSE进度；仅用自己的测试任务演示删除 |
| 7 | /submission | 选择已完成任务，生成校验并预览CSV；解释补位是导出规则 |
| 8 | /assistant | 查询演示编号并关联检查，提问、查看依据、停止或重新生成，演示审阅草稿 |

## 建议展示的问题

- 当前检查有哪些较高评分，哪些信息需要复核？
- 为什么所有分数低于阈值仍不能判断正常？
- Grad-CAM颜色能否确认病灶位置？
- 没有既往记录时，助手如何说明不能比较变化？

## 需要单独准备的演示数据

批量目录应遵循数据集扫描约定，见API_CONTRACT.md。随附三张独立来源样例可分别用于单次上传；其中来源页描述为肺炎的样例可观察模型分数，但不能保证超过阈值。批量接口验收数据集仍需本地准备，不能混为同次检查。
